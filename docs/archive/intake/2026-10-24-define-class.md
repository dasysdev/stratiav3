# Definición de la clase para el modelo de demanda

La **clase objeto del modelo de demanda** se define partiendo de una **clase general** e incorporando **tantas especializaciones como sean relevantes** para las necesidades informativas del producto estudiado.

## Regla metodológica

1. **Identificar la clase general** a la que pertenece el producto.
2. **Reconocer las especializaciones pertinentes** por uso, material, función u otras características, siempre que introduzcan o modifiquen cuestiones informativas relevantes.
3. **Componer la clase de estudio** mediante la clase general y todas las especializaciones aplicables. No es necesario que formen una jerarquía estricta: pueden ser facetas que concurren.
4. **Construir el modelo de demanda** integrando los requisitos comunes y los específicos, sin duplicados y revisando su aplicabilidad e importancia relativa.

## Ejemplo

**Juegos de sábanas** (clase general) + **uso invernal** (especialización) + **tejido de coralina** (especialización) → **clase de estudio: juegos de sábanas de coralina para invierno**.

La medida de cama (por ejemplo, 90 cm) caracteriza una variante, pero no obliga por sí sola a crear otra clase.

**Principio:** buscar la **especificidad informativa necesaria**, no el mayor número posible de subclases.
